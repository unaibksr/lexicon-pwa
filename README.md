# Lexicon - Personal Dictionary PWA

A modern, responsive, dark-themed personal dictionary Progressive Web App built with React, Vite, and Tailwind CSS.

## Features
- **Responsive PWA Shell**: Seamless mobile view and desktop split-pane UI.
- **Offline First**: Stores dictionary data locally.
- **Free Dictionary API Integration**: Look up definitions and auto-fill word entries.
- **Pronunciation Support**: Built-in speech synthesis.
- **Tag Filtering & Search**: Quickly search across vocabulary entries.

## Quick Start

1. Extract the project files.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production / PWA distribution:
   ```bash
   npm run build
   ```
